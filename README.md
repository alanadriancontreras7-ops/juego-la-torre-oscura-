# 🏰 La Torre Oscura

Juego web estilo RPG / Dungeon Crawler desarrollado con Python y Flask. Explora la torre, enfrenta enemigos y administra tus recursos para llegar a la cima.

---

## 🎮 Características
- Sistema de combate por turnos / exploración.
- Generación de sprites e interfaz visual.
- Persistencia de datos de la partida con base de datos.

---

## 🚀 Requisitos Previos

- Python 3.8 o superior instalado.
- Git instalado.
